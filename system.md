# System Architecture

## Hardware Components
* **Parabolic Dish:** 120 cm offset/prime focus satellite dish.
* **Feedhorn:** Custom-built cantenna optimized for 1420 MHz.
* **LNA:** Nooelec SAWbird+ H1 (integrated SAW filter).
* **Receiver:** RTL-SDR Blog V3.

## Software & Processing
* Data acquisition scripts, GNU Radio blocks, and Python-based spectral analysis pipelines.
