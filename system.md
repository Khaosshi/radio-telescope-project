# Hardware Architecture

Our 21 cm neutral hydrogen radio telescope system consists of the following key hardware components:

* **Parabolic Dish Antenna:** 120 cm offset/prime focus satellite dish used for high gain signal collection.
* **Feedhorn:** Custom-built cantenna feedhorn optimized for the 1420 MHz hydrogen line frequency.
* **Low Noise Amplifier (LNA):** Nooelec SAWbird+ H1, featuring an integrated SAW filter designed specifically for radio astronomy to suppress out-of-band interference.
* **Receiver:** RTL-SDR Blog V3 (Software Defined Radio) for downconverting and digitizing the RF signal.
* **Processing Unit:** PC / Raspberry Pi setup running custom data acquisition and spectral analysis software (Python / GNU Radio).
